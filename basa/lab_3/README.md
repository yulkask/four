# Лабораторная 3. Учёт квартплаты: сальдо, начисления, платежи

## Запуск

```bash
docker compose up -d --build
```

| Что | Адрес |
|---|---|
| Веб-интерфейс | http://localhost:8001 |
| phpMyAdmin | http://localhost:8081 |
| MySQL | `localhost:3308`, БД `kvartplata`, пользователь `kvartplata` / `kvartplata` |

При первом запуске MySQL выполняет `sql/01_schema.sql`, `02_data.sql`, `03_procedures.sql`.
Чтобы пересоздать БД с нуля: `docker compose down -v && docker compose up -d`.

## Таблицы

Знак сальдо: **«+» — долг**, **«−» — переплата**.
Сальдо на конец месяца = сальдо на начало + начислено − оплачено.

**accounts** — справочник лицевых счетов (на него ссылаются три основные таблицы)

| Поле | Тип | Описание |
|---|---|---|
| id | INT, PK | |
| account_no | VARCHAR(10), уникальное | номер лицевого счёта (6–10 цифр) |
| flat | SMALLINT, уникальное | номер квартиры |
| owner | VARCHAR(150) | квартиросъёмщик |
| area | DECIMAL(6,2) | площадь, м² |
| residents | TINYINT | число проживающих |

**saldo** — сальдо по лицевому счёту на начало месяца

| Поле | Тип | Описание |
|---|---|---|
| id | INT, PK | |
| account_id | FK → accounts | |
| period | DATE (1-е число) | месяц, на начало которого зафиксировано сальдо |
| amount | DECIMAL(12,2) | сумма сальдо |

Уникальность: `(account_id, period)`.

**charges** — начисления по лицевому счёту

| Поле | Тип | Описание |
|---|---|---|
| id | INT, PK | |
| account_id | FK → accounts | |
| period | DATE (1-е число) | расчётный месяц |
| service | VARCHAR(50) | услуга (содержание жилья, отопление, вода…) |
| amount | DECIMAL(12,2) | сумма; отрицательная — перерасчёт |

Уникальность: `(account_id, period, service)`.

**payments** — платежи по лицевому счёту

| Поле | Тип | Описание |
|---|---|---|
| id | INT, PK | |
| account_id | FK → accounts | |
| pay_date | DATE | дата поступления (платёж учитывается в этом месяце) |
| amount | DECIMAL(12,2) > 0 | сумма |
| source | VARCHAR(30) | способ оплаты: банк, онлайн, касса, почта |
| doc_no | VARCHAR(20), может быть пустым | номер платёжного документа |

## Хранимые процедуры

| Процедура | Что выводит |
|---|---|
| `fn_saldo(account_id, date)` | функция: сальдо на начало даты (последняя запись в `saldo` + начисления − платежи после неё) |
| `sp_turnover_sheet(year)` | **оборотная ведомость**: по каждой квартире входящее сальдо и для каждого месяца начислено, оплачено, сальдо на конец месяца |
| `sp_account_turnover(account_id, year)` | **ведомость по квартире**: помесячные начисления и оплаты, сальдо на начало года, итоги, долг за предыдущие периоды, итого к оплате |
| `sp_debtors(date)` | **должники по категориям** на 1-е число месяца: начислено за последний месяц, сальдо, сумма в колонке «1 / 2 / 3 / свыше 3 месяцев» |
| `sp_close_month(period)` | закрытие месяца: записывает в `saldo` сальдо на начало следующего месяца |

Категория должника — наименьшее число последних месяцев, начисления за которые покрывают сумму долга.
Например, если долг 11 232.38, а начисления за сентябрь и август 5 254.99 + 5 977.39 = 11 232.38, то долг относится к категории «2 месяца».
