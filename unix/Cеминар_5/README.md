# Семинар 5: вывод содержимого каталога

В папке находятся оба варианта задания.

- `dirlist.c` — основной вариант: использует `opendir`, `readdir` и `closedir`.
  Печатает тип, права, число ссылок, владельца, группу, размер и имя, подобно
  `ls -l`. Символические ссылки выводятся с их целью.
- `dirlist_scandir.c` — вариант через `scandir`. Вывод имеет тот же формат,
  что и основной вариант; отличается только способом чтения каталога.

Сборка:

```sh
cd unix/Cеминар_5
make
```

Запуск (без аргумента используется текущий каталог):

```sh
./dirlist /путь/к/каталогу
./dirlist_scandir /путь/к/каталогу
```

Скрытые записи (имена, начинающиеся с точки) не выводятся — как у обычного
вызова `ls` без `-a`.
