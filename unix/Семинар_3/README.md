# Сервер на FIFO

## Сборка

В терминале перейдите в папку работы и скомпилируйте программы:

```sh
cd unix/Семинар_3
make
```

Будут созданы исполняемые файлы `server` и `client`.

## Запуск

1. В первом терминале запустите сервер:

   ```sh
   ./server
   ```

   Сервер напечатает путь своего именованного канала: `/tmp/fifo_server`.

2. В каждом следующем терминале запустите клиента:

   ```sh
   ./client
   ```

   Можно одновременно запустить несколько клиентов. Каждый создаёт собственный FIFO с именем вида `/tmp/fifo_client_<PID>`.

3. Через 30 секунд каждый клиент выведет число принятых символов, закроет и удалит свой FIFO. Серверный дочерний процесс увидит закрытие канала и завершится.

4. Для штатной остановки сервера нажмите `Ctrl+C`: сервер удалит свой FIFO.

## Другой путь к серверному FIFO

Один и тот же нестандартный путь нужно передать и серверу, и всем клиентам:

```sh
./server /tmp/my_server_fifo
./client /tmp/my_server_fifo
```

Если запуск был аварийно прерван и файл FIFO остался в `/tmp`, удалите только известный файл канала и запустите сервер снова:

```sh
rm -f /tmp/fifo_server
```
