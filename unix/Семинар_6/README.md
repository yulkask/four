# Семинар 6: просмотр текста с помощью S-Lang

- `slang.c` — исходный пример (перекодирован из CP1251 в UTF-8).
- `slang_file.c` — задание b: строки загружаются из файла.
- `sample.txt` — файл для проверки.

Сборка (на macOS нужна библиотека `brew install s-lang`):

```sh
cd unix/Семинар_6
make
```

Запуск:

```sh
./slang                     # исходный пример
./slang_file sample.txt     # просмотр файла
```

## a) Исходный пример `slang.c`

Программа создаёт двусвязный список из строк `String 1` … `String 99` и
показывает его в рамке высотой 10 строк. Для прокрутки используется
структура `SLscroll_Window_Type`.

Клавиши обрабатываются в цикле через `SLkp_getkey()`. Эта функция распознаёт
escape-последовательности стрелок и возвращает коды `SL_KEY_UP` и
`SL_KEY_DOWN`. Для этого до цикла вызывается `SLkp_init()`.

| Клавиша | Действие |
|---------|----------|
| ↑ | `SLscroll_prev_n(&win, 1)`, затем `top_window_line = current_line`: окно сдвигается на строку вверх |
| ↓ | `SLscroll_next_n(&win, 1)` и то же присваивание: окно сдвигается на строку вниз |
| q | `goto l_exit`: освобождение списка и восстановление терминала |
| другие | игнорируются, экран перерисовывается |

В примере нет отдельного курсора. Всегда подсвечена первая строка окна:
`SLsmg_reverse_video()` вызывается перед циклом вывода, а
`SLsmg_normal_video()` — после первой строки. Цвета из `SLtt_set_color`
задают вид обычного текста (0) и инверсного (1).

В исходный пример внесены три исправления, без которых он работал бы с ошибками:
- добавлен `#include <stdio.h>` для `sprintf`;
- буфер `str[11]` увеличен: строка `"  String 99"` занимает 11 символов плюс `'\0'`, поэтому буфер переполнялся;
- строки, созданные функцией `SLmake_string`, освобождаются через `SLfree`, а не `free`.

## b) `slang_file.c`: чтение строк из файла

Файл читается построчно функцией `getline` в двусвязный список до
инициализации экрана. Поэтому ошибка открытия выводится обычным сообщением
(`perror`). Символы `\n` и `\r` в конце строк отбрасываются.

По сравнению с примером:
- в структуру `Line` добавлено поле `flags`, и её начало совпадает с
  `SLscroll_Type`. Приведение к `SLscroll_Type *` теперь корректно;
- двигается текущая строка (подсвечена зелёным), а `SLscroll_find_top`
  прокручивает окно вслед за ней;
- окно занимает весь терминал. Высота пересчитывается при изменении размера
  (`SIGWINCH` → `SLsmg_reinit_smg`);
- как в `ncurses_example.c`, цвета заданы несколькими парами (`init_pair` ↔
  `SLtt_set_color`). Заголовок и строка состояния выделены отдельным цветом;
- добавлены номера строк, а для кириллицы включён UTF-8 (`SLutf8_enable`).

| Клавиша | Действие |
|---------|----------|
| ↑ / k, ↓ / j | на строку вверх / вниз |
| PgUp, PgDn / пробел | на страницу (`SLscroll_pageup` / `SLscroll_pagedown`) |
| Home / g, End / G | в начало / конец файла |
| ←, → | горизонтальная прокрутка длинных строк |
| q | выход |
