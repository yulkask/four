# Клиент TCP-чата: как запустить

Сервер запущен на ноутбуке одного из участников команды. Вам нужно только запустить клиент и подключиться к серверу.

## 1. Проверить .NET

Нужен тот же .NET SDK, что и для Задания 2. Откройте терминал (на Windows: PowerShell или «Командная строка») и выполните:

```sh
dotnet --version
```

- Если версия **10.x**, всё готово.
- Если версия **8.x** или **9.x**, откройте `ChatClient.csproj` в текстовом редакторе и замените `net10.0` на `net8.0` (или `net9.0`).
- Если команда не найдена, установите **.NET SDK** (не Runtime) с https://dotnet.microsoft.com/download и перезапустите терминал.

## 2. Подключиться к той же сети, что и сервер

Все должны быть в одной Wi-Fi-сети или на одной точке доступа. VPN на время проверки выключите.

## 3. Запустить

Перейдите в папку с клиентом и запустите его, указав IP-адрес сервера (его сообщит участник, у которого запущен сервер) и свой ник:

```sh
cd путь/к/КЛИЕНТ_ДЛЯ_ОТПРАВКИ
dotnet run -- 192.168.1.42 Ivan
```

Вместо `192.168.1.42` подставьте адрес сервера, вместо `Ivan` свой ник. Ник: от 1 до 20 символов, без пробелов, у всех разный (регистр не учитывается: `Ivan` и `ivan` считаются одним ником).

Если запустить просто `dotnet run`, программа сама спросит адрес и ник. Первый запуск займёт несколько секунд: проект соберётся.

После подключения появится:

```
Подключено к 192.168.1.42:50001. Команды: /list, /nick новыйник, /msg текст, /quit.
```

## 4. Как пользоваться

| Что ввести           | Что произойдёт                                                    |
|----------------------|-------------------------------------------------------------------|
| `текст` + Enter      | Остальные увидят `[ваш_ник]: текст`. У себя сообщение не дублируется |
| `/msg текст`         | То же, что просто текст                                           |
| `/list`              | Список участников онлайн: `*** online (N): ...`                   |
| `/nick новыйник`     | Смена ника, все увидят `*** старый is now known as новый`         |
| `/quit` или Ctrl+C   | Выход, остальные увидят `*** ваш_ник left`                        |

Строки, начинающиеся с `***`, это системные сообщения сервера: кто вошёл и вышел, ошибки, список участников.

## Если что-то не работает

| Проблема | Что сделать |
|----------|-------------|
| `Не удалось подключиться ... Connection refused` / «Подключение не установлено» | Проверьте IP-адрес и то, что сервер запущен. Порт по умолчанию 50001. |
| `Не удалось подключиться ... timed out` | Вы в разных сетях, включён VPN или брандмауэр сервера блокирует порт. Сообщите об этом участнику с сервером. |
| `*** error: nick is already taken` | Такой ник уже занят: запустите клиент заново с другим ником. |
| `*** соединение с сервером потеряно` | Сервер остановлен или пропала сеть. Запустите клиент заново, когда сервер снова заработает. |
| Ошибки сборки после копирования папки | Удалите папки `bin` и `obj` внутри папки клиента и запустите снова. |
| На Windows русские буквы превращаются в «кракозябры» или пропадают | Запускайте клиент в Windows Terminal или пишите латиницей. |
