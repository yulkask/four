# P2P-локатор сети и широковещательный чат (C#)

Консольная программа на неблокирующих UDP-сокетах. Работает в локальной сети без центрального сервера и совместима с программами других студентов, если они следуют протоколу аудитории.

## Протокол

- UDP, порт `50000`. Отправка на `255.255.255.255:50000`, приём через `bind` на `0.0.0.0:50000`, включён `SO_BROADCAST`.
- Пакет в UTF-8 имеет формат `ТИП|Имя|Текст`. При разборе строка делится максимум на 3 части. Если частей 2, текст пустой.
- Типы пакетов:

  | Тип        | Когда отправляется                  | Что делает получатель                          |
  |------------|-------------------------------------|------------------------------------------------|
  | `DISCOVER` | при старте                          | добавляет узел в таблицу и сразу шлёт `BEACON` |
  | `BEACON`   | раз в 10 с и в ответ на `DISCOVER`  | добавляет узел или обновляет время             |
  | `MSG`      | когда пользователь пишет сообщение  | выводит `Имя: Сообщение`, обновляет узел       |
  | `BYE`      | при штатном выходе                  | сразу удаляет узел                             |

- Если от узла 45 секунд не было пакетов, он удаляется из таблицы.
- Размер пакета не больше 1024 байт. Слишком длинный текст обрезается по границе символа.
- Некорректные пакеты (неизвестный тип, пустое имя, не UTF-8) молча игнорируются.
- Ключ таблицы узлов — IP отправителя. Имя обновляется при каждом пакете.
- Свои пакеты (broadcast возвращается отправителю) отсеиваются по локальным IP-адресам.

## Сборка и запуск

Нужен .NET SDK 10. Если установлен .NET 8, замените в `P2PChat.csproj` `net10.0` на `net8.0`.

```sh
cd razr_rasp_prog/Задание_2
dotnet run -- Ivanov
```

Если имя не передано аргументом, программа спросит его при старте.

Команды в чате:

- любой текст — отправить сообщение всем;
- `/list` — таблица активных узлов (имя, IP, время последнего сообщения);
- `/quit` или Ctrl+C — выход с отправкой `BYE`.

Две копии программы на одном компьютере не запустятся, потому что обе попытаются занять порт 50000. Проверяйте на разных компьютерах в одной Wi-Fi-сети (например, через точку доступа телефона). Разрешите входящий UDP на порт 50000 в файрволе.

## Логи

Всё, что программа отправляет и получает, дописывается в файл `p2p_chat.log` в текущей папке: время, направление, адрес отправителя или получателя, размер в байтах и содержимое. Туда же попадают свои отражённые пакеты и отброшенные некорректные пакеты с пометкой.

```
[2026-09-29 12:25:05.813] ПОЛУЧЕНО от 192.168.43.17:50000, 16 байт: DISCOVER|Ivanov|
[2026-09-29 12:25:05.814] ОТПРАВЛЕНО на 255.255.255.255:50000, 12 байт: BEACON|Test|
```

## Устройство программы

Сокет переведён в неблокирующий режим (`socket.Blocking = false`). Главный цикл делает следующее:

1. Ждёт данные на сокете не дольше 100 мс (`Poll`), затем читает все пришедшие датаграммы через `ReceiveFrom`, пока не получит `WouldBlock`.
2. Обрабатывает строки, введённые пользователем.
3. Отправляет `BEACON` по таймеру и удаляет узлы, от которых давно не было пакетов.

`Console.ReadLine` блокирует поток, поэтому ввод читается в отдельном потоке и передаётся в главный цикл через очередь. Все операции с сокетом выполняются только в главном цикле.
