# SMTP: задания 1 и 2 для клиентов

Что лежит в папке:

| Файл                                   | Зачем                                              |
|----------------------------------------|----------------------------------------------------|
| `cms159.zip`                           | Почтовый сервер Courier (задание 1, только Windows) |
| `SmtpClientApp.csproj`, `Program.cs`   | SMTP-клиент (задание 2)                            |

Как распределены роли: у каждого из вас на компьютере работает свой Courier, и ваш клиент отправляет письма в него. SMTP-сервер из задания 3 запущен на ноутбуке участника команды. В конце вы отправляете письмо и на этот сервер.

## Задание 1. Установить почтовый сервер Courier

1. Распакуйте `cms159.zip` в любую папку, например на рабочий стол.
2. Запустите `cms159\CourierMS.exe`. Когда брандмауэр Windows спросит про доступ, нажмите «Разрешить».
3. Щёлкните правой кнопкой по **«SMTP-сервис»** и выберите **«Свойства»**:
   - Порт: `25`, тайм-аут: `600`;
   - включите «Требовать аутентификации клиентов»;
   - включите оба метода: «PLAIN, LOGIN» и «CRAM-MD5»;
   - нажмите OK.
4. Щёлкните правой кнопкой по **«Пользователи»** и откройте пользователя, например `Stud01` (двойным щелчком), или создайте нового:
   - Имя почтового ящика: `Stud01`, справа будет `@domain.local`;
   - Пароль: придумайте и запомните;
   - Почтовая папка: `Mail\Mailbox\Stud01\` — сюда будут приходить письма для этого пользователя;
   - нажмите OK.

Запомните:
- адрес почты: `Stud01@domain.local`;
- логин для аутентификации: тот же адрес `Stud01@domain.local`.

Окно Courier не закрывайте: пока оно открыто, сервер работает.

## Задание 2. SMTP-клиент

### Проверить .NET

Откройте PowerShell (или «Командную строку») и выполните:

```sh
dotnet --version
```

- Если версия **10.x**, всё готово.
- Если версия **8.x** или **9.x**, откройте `SmtpClientApp.csproj` в текстовом редакторе и замените `net10.0` на `net8.0` (или `net9.0`).
- Если команда не найдена, установите **.NET SDK** (не Runtime) с https://dotnet.microsoft.com/download и перезапустите терминал.

### Как работает клиент

Клиент подключается к SMTP-серверу и выполняет команды по порядку: `EHLO localhost` → (если задан логин) `AUTH` → `MAIL FROM` → `RCPT TO` → `DATA` → письмо с заголовками `From`, `To`, `Subject` → `\r\n.\r\n` → `QUIT`. Весь диалог выводится в консоль: `C:` — команды клиента, `S:` — ответы сервера. Пароль в консоли заменяется на `********`.

### Шаг 1. Отправить письмо в свой Courier

```sh
cd путь\к\КЛИЕНТ_ДЛЯ_ОТПРАВКИ
dotnet run -- --user Stud01@domain.local --password ВАШ_ПАРОЛЬ --from Stud01@domain.local --to Stud01@domain.local
```

Подставьте своего пользователя и пароль. Первый запуск займёт несколько секунд: проект соберётся.

Что должно получиться:
- в конце вывода: `S: 250 ...`, `C: QUIT`, `S: 221 ...` и строка **«Письмо успешно отправлено.»**;
- в папке `cms159\Mail\Mailbox\Stud01\` появился файл письма. Откройте его Блокнотом: внутри заголовки `From`, `To`, `Subject: Test from SMTP Client` и текст.

### Шаг 2. Отправить письмо на сервер участника команды

Участник с сервером сообщит свой IP-адрес. Все должны быть в одной Wi-Fi-сети, VPN выключен.

```sh
dotnet run -- --host 192.168.1.42 --port 2525 --from ваше_имя@localhost --to user@localhost --text "Привет от ваше_имя!"
```

Вместо `192.168.1.42` подставьте адрес сервера. Этот сервер не требует аутентификации, поэтому `--user` и `--password` не указывайте.

На экране участника с сервером появится ваше письмо: отправитель, получатель и всё тело с заголовками.

### Все параметры клиента

| Параметр     | По умолчанию                  | Что задаёт                                             |
|--------------|-------------------------------|--------------------------------------------------------|
| `--host`     | `localhost`                   | Адрес SMTP-сервера                                     |
| `--port`     | `25`                          | Порт                                                   |
| `--from`     | `test@localhost`              | Отправитель                                            |
| `--to`       | `user@localhost`              | Получатель                                             |
| `--subject`  | `Test from SMTP Client`       | Тема письма                                            |
| `--text`     | английская строка-приветствие | Текст письма                                           |
| `--user`     | —                             | Логин для AUTH. Если не указан, аутентификации не будет |
| `--password` | —                             | Пароль для AUTH                                        |

## Если что-то не работает

| Проблема | Что сделать |
|----------|-------------|
| `Не удалось подключиться к localhost:25` | Courier не запущен или SMTP-сервис остановлен. Проверьте окно Courier. |
| `ожидался код 235, получен: 535 ...` | Неверный логин или пароль. Логин нужно указывать полностью: `Stud01@domain.local`. |
| `ожидался код 250, получен: 530 ...` или `5xx` после `MAIL FROM` | Не указаны `--user` и `--password`, а в Courier включена обязательная аутентификация. |
| `ожидался код 250, получен: 550 ...` после `RCPT TO` | Такого получателя нет в Courier. Используйте адрес существующего пользователя `@domain.local`. |
| `Не удалось подключиться к 192.168...:2525` — refused или timed out | Проверьте IP-адрес. Убедитесь, что вы в одной сети с сервером и VPN выключен. Сообщите участнику с сервером: возможно, его сервер не запущен с `--lan` или его брандмауэр блокирует порт. |
| Ошибки сборки после копирования папки | Удалите папки `bin` и `obj` внутри этой папки и запустите снова. |
| Русские буквы в консоли отображаются «кракозябрами» | Запускайте в Windows Terminal или пишите текст латиницей. |
