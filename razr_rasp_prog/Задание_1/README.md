# TCP-клиент и сервер

Сервер принимает строку, добавляет к ней ` Привет от сервера!` и возвращает результат. Обе программы выводят в консоль всё, что отправили и получили.

## Сборка

```sh
cd razr_rasp_prog/Семинар_6
make
```

## Запуск

В первом терминале:

```sh
./server
```

Во втором терминале:

```sh
./client 192.168.1.42
```

Вместо `192.168.1.42` укажите IP-адрес компьютера, на котором запущен сервер. Если аргумент не передать, клиент попросит IP-адрес сам. Затем он попросит ввести строку. Сервер остаётся запущенным и может обслужить следующего клиента после завершения предыдущего.

Сервер использует порт `12789`. Для запуска на одном компьютере укажите `127.0.0.1`; для двух компьютеров в одной Wi-Fi/LAN-сети используйте локальный IP компьютера сервера. Разрешите входящие подключения к этому порту в файрволе сервера.

Для запуска на разных компьютерах следуйте отдельной пошаговой инструкции: [ИНСТРУКЦИЯ_ДЛЯ_ДВУХ_КОМПЬЮТЕРОВ.md](ИНСТРУКЦИЯ_ДЛЯ_ДВУХ_КОМПЬЮТЕРОВ.md).

`shutdown(..., SHUT_WR)` у клиента отмечает конец отправляемой строки. Это важно для TCP: TCP передаёт поток байтов, поэтому один вызов `recv` не гарантирует получение всей строки.
