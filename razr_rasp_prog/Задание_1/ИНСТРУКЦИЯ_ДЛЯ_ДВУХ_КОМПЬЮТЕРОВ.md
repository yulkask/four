# Запуск TCP-клиента и сервера на двух компьютерах

## Перед началом

Компьютер с сервером и компьютер с клиентом должны находиться в одной локальной сети: например, быть подключены к одному Wi-Fi. Мобильная сеть, гостевой Wi-Fi и разные сети обычно не подходят без дополнительной настройки маршрутизатора.

Работа использует TCP-порт `12789`.

| Роль | Что запускает |
| --- | --- |
| Вы | Сервер: `server.cpp` / `./server` |
| Одногруппник | Клиент из папки `КЛИЕНТ_ДЛЯ_ОТПРАВКИ` / `./client ВАШ_IP` |

## Действия на вашем компьютере — сервер

1. Откройте терминал в папке работы:

   ```sh
   cd /Users/yulia/Desktop/four/razr_rasp_prog/Семинар_6
   ```

2. Соберите сервер:

   ```sh
   make
   ```

3. Узнайте локальный IPv4-адрес компьютера. На macOS при подключении по Wi-Fi:

   ```sh
   ipconfig getifaddr en0
   ```

   Результат выглядит примерно так: `192.168.1.42`. Именно этот адрес нужно передать одногруппнику. Не передавайте `127.0.0.1`: этот адрес всегда означает «этот же компьютер» и для второго компьютера не работает.

   Если команда не вывела адрес, откройте **Настройки системы → Сеть → Wi-Fi** и найдите IPv4-адрес. При проводном подключении он может быть у интерфейса Ethernet.

4. Запустите сервер:

   ```sh
   ./server
   ```

   В окне появится сообщение о запуске на порту `12789`. Не закрывайте это окно до завершения проверки.

5. Если macOS спросит, разрешить ли программе принимать входящие подключения, нажмите **«Разрешить»**.

6. Отправьте одногруппнику папку `КЛИЕНТ_ДЛЯ_ОТПРАВКИ` и свой IP-адрес, например: `192.168.1.42`.

## Действия на компьютере одногруппника — клиент

1. Распакуйте полученную папку `КЛИЕНТ_ДЛЯ_ОТПРАВКИ`.

2. Откройте терминал в этой папке и соберите программу:

   ```sh
   make
   ```

3. Запустите клиент с IP-адресом компьютера сервера. Вместо примера укажите адрес, который прислали вы:

   ```sh
   ./client 192.168.1.42
   ```

4. Когда появится запрос, введите текст, например:

   ```text
   Здравствуйте
   ```

5. Ожидаемый результат у клиента:

   ```text
   [Клиент] Отправлено: Здравствуйте
   [Клиент] Получено: Здравствуйте Привет от сервера!
   ```

   На сервере одновременно появятся записи о подключении клиента, полученной строке и отправленном ответе.

## Если соединение не устанавливается

| Сообщение или ситуация | Что проверить |
| --- | --- |
| `connect: Connection refused` | Сервер не запущен, указан неверный IP или сервер завершился. Запустите `./server` и перепроверьте адрес. |
| `connect: Operation timed out` | Компьютеры, вероятно, в разных сетях либо входящее соединение блокирует файрвол. Подключитесь к одному Wi-Fi и разрешите порт `12789` для сервера. |
| Указан `127.0.0.1`, но соединения нет | `127.0.0.1` годится только для запуска клиента и сервера на одном компьютере. Для двух компьютеров нужен адрес вида `192.168.x.x` или `10.x.x.x`. |
| Порт уже занят при запуске сервера | Уже запущен другой экземпляр `./server`. Остановите его сочетанием `Ctrl+C`. |

## Завершение

После проверки остановите сервер в его терминале сочетанием `Ctrl+C`.
